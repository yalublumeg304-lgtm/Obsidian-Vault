Декомпозиция - разделение сложной задачи на подзадачи
Декомпозиция для подготовки к собеседованию:
 1. Анализ тенденций 
 (perplexity.ai - поиск со ссылками на достоверные источники.)
 В промпте отразить требование к пояснению каждой ссылки "зачем это нужно"
 Подбор актуальных источников (не более пяти лет).
2. Подбор требований к выбираемой должности (обязательные, дополнительные).
3. Проведение тестового собеседования для определения текущих навыков, сильных/слабых сторон.
 Назначить LLM роль (интервьюер, который проверяет текущие навыки собеседуемого)
 Определить длительность собеседования.
 Определить формат собеседования (список вопросов, на который человек отвечает текстом или голосовой чат)
4. Подведение итогов тестового собеседования (summary) - краткий отчет с выводами. (анализировать **КРИТИЧЕСКИ!**)
На основе summary подобрать план (roadmap) для изучения/подготовки.(Диаграмму для roadmap можно составлять в svg или 'bermaid' форматах)
5. После обучения - "боевое" собеседование
Придумать легенду интервьюера. В какой компании работает, на какой должности, как зовут и тд.


==Прием "взгляд со стороны"==
==Если в задаче есть несколько версий, из которой нужно выбрать одну - опишите запрос так, будто у каждого варианта есть свой автор(человек), который спорит со всем остальными, а вам необходимо выбрать наилучший из них.==

 **Задание 2. разработка сайта-визитки для резюме**
 Правило 1 - чувствительные данные
 Для личных данных лучше делать заглушки и просить ИИ указать комментарие в коде где необходимо исправление.
Правило 2 - определить необходимые пункты в резюме. При желании, можно попросить ИИ спросить у вас информацию по ним, чтобы не указывать сразу в одном запросе.

Правило 3 - определиться со стилем резюме, учитывая предметную область, а так же актуальные и современные возможности движка 'html/css/js'
